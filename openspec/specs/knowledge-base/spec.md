# knowledge-base Specification

## Purpose
为自学中的大学生提供一份来自自己真实资料的知识底座：把上传的课件与讲义转成可学习、可出题、可追溯的知识点，并在演示场景下提供预置课程兜底。

## Requirements

### Requirement: 资料上传与格式校验

系统 MUST 允许用户上传 TXT、MD、PDF 三种格式的资料文件，并在格式不符时给出明确提示。

#### Scenario: 上传受支持格式

- **WHEN** 用户选择一份 TXT、MD 或 PDF 文件并确认上传
- **THEN** 系统接受该文件，并显示文件名与解析状态"处理中"

#### Scenario: 上传不支持的格式

- **WHEN** 用户选择 PPTX 或 DOCX 文件
- **THEN** 系统拒绝上传，并提示"当前仅支持 TXT / MD / PDF"

### Requirement: 文档解析与知识点切分

系统 MUST 将上传资料解析为纯文本并切分为若干知识点，每个知识点 MUST 带有名称、顺序与所属章节信息。

#### Scenario: 正常解析

- **WHEN** 资料解析成功
- **THEN** 系统生成知识点列表，每个知识点包含名称、顺序和所属章节

#### Scenario: 解析失败

- **WHEN** PDF 解析失败或提取到的文本过少
- **THEN** 系统把该资料标记为"解析失败"，提示改用 MD 或 TXT，且不影响其他资料

### Requirement: 知识点溯源到段落

系统 MUST 为每个知识点记录来源文档名与段落序号，用户查看知识点时 MUST 能看到来源并跳回对应段落；讲解与答疑中的来源引用 MUST 以角标或折叠形式呈现，MUST NOT 在正文中逐段刷屏，且展开后 MUST 仍能看到完整出处（文档名与段落序号）并定位到对应段落。

#### Scenario: 查看知识点出处

- **WHEN** 用户在知识点详情中点击"查看出处"
- **THEN** 系统展示来源文档名与段落序号，并定位到该段落文本

#### Scenario: 生成回答时引用出处

- **WHEN** 智能体基于知识库生成讲解或答疑内容
- **THEN** 回答中的引用以角标或折叠形式标注，正文保持连贯，不被"文档名 + 段落序号"的长串文字打断

#### Scenario: 展开引用溯源

- **WHEN** 用户点击回答中的引用角标或折叠条
- **THEN** 系统展开显示完整出处（文档名与段落序号），并可定位到对应段落文本

### Requirement: 预置课程包

系统 MUST 内置 1 门预置课程《大学计算机基础》及配套可公开讲义，且在无任何用户上传资料时 MUST 仍能完成完整学习流程。

#### Scenario: 首次打开且无上传资料

- **WHEN** 用户首次打开系统且未上传任何文件
- **THEN** 系统展示预置课程及其知识点，用户可直接选择该课程开始学习

### Requirement: 资料与知识点双向关联

系统 MUST 支持从资料查看其派生知识点，也 MUST 支持从知识点回到来源资料段落；知识点列表 MUST 以卡片形式展示，每张卡片 MUST 至少包含知识点标题与内容摘要，MUST 支持展开查看完整详情与出处。

#### Scenario: 从资料查看知识点

- **WHEN** 用户打开一份已解析资料
- **THEN** 系统以卡片列表展示该资料切分出的全部知识点，每张卡片显示标题与摘要，点击可展开查看详情与出处

### Requirement: 资料列表可见

系统 MUST 在知识库页面列出已上传资料及其解析状态，让用户知道当前知识库里有什么。

#### Scenario: 查看知识库列表

- **WHEN** 用户进入知识库页面
- **THEN** 系统显示每份资料的文件名、格式与解析状态（处理中 / 成功 / 失败）
