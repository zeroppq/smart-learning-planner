# 知识库格式支持说明

## 支持哪些文件

| 格式 | 扩展名 | 说明 |
|------|--------|------|
| 纯文本 | `.txt` | 直接读取文字，按空行分段，每 5 段合成一个知识点 |
| Markdown | `.md` / `.markdown` | 按标题切分章节，二级及以下标题各成一个知识点 |
| PDF | `.pdf` | 自动抽取文字；扫描版 PDF（图片）抽不出文字，会提示解析失败 |

单个文件不超过 10MB。

## 不支持哪些文件

- `.pptx` / `.docx`：当前不解析，请先另存为 PDF 或复制成 MD / TXT。
- 扫描件 PDF、纯图片 PDF：没有文字层，抽取不到内容。
- 加密或有密码的 PDF。

## 上传步骤

1. 打开「知识库」页面。
2. 点「选择文件」，选中你的 TXT / MD / PDF。
3. 点「上传并解析」，等待状态变为「解析成功」。
4. 在资料列表中点这份资料，下面会列出切分出的知识点。
5. 点某个知识点，页面底部显示「原文出处」：来源文档名与第几段。

## 解析失败了怎么办

| 现象 | 原因 | 处理办法 |
|------|------|----------|
| 提示「PDF 解析失败」 | PDF 结构损坏或为扫描件 | 改用 MD / TXT，或用其他工具把 PDF 转成文本 |
| 提示「提取到的文字太少」 | 文件几乎没有正文 | 检查文件内容，或换一份资料 |
| 提示「当前仅支持 TXT / MD / PDF」 | 上传了 PPTX / DOCX 等 | 先转换格式再上传 |
| 一直显示「处理中」 | 文件较大仍在解析 | 等几秒后刷新页面；仍无变化则重新上传 |

## 关于「预置课程」

系统内置一份《大学计算机基础》占位讲义，用于保证没有任何上传资料时也能开始学习。它带「预置」标记，不会重复出现。正式讲义到位后，替换讲义内容并重新导入即可覆盖。

## 关于出处

每个知识点记录两个信息：

- 来源文档名：例如 `大学计算机基础（预置占位讲义）.md`
- 段落序号：例如「第 12 段」，指该知识点在全文中的段落位置

点「原文出处」可以直接看到那一段原文，方便核对 AI 讲解是否有依据。
