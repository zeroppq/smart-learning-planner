# 演示重置说明

录演示视频需要反复重来。本说明提供两种一键重置模式。

## 一、前提

- 开发服务已启动（`npm run dev`），地址 http://localhost:3000 。
- 在项目根目录执行命令。

## 二、两种模式

### 模式 1：全新开始（fresh）

清空所有学习记录，只保留《大学计算机基础》讲义（22 个知识点）和一个学习目标、一份计划，**没有任何判定结果**。

```
node --experimental-strip-types scripts/reset-demo.mjs fresh
```

适合演示"从说目标开始"的完整流程。

### 模式 2：演示主线（demo）

在"全新开始"的基础上，把路线图前 2 个知识点标记为**待回炉**，进度页显示 2 个待回炉，可直接演示"督学判不过 → 规划师调整 → 确认 → 版本递增"这条核心链路。

```
node --experimental-strip-types scripts/reset-demo.mjs demo
```

适合演示比赛 20 分得分点的调整画面。

## 三、重置后怎么确认成功

```
node scripts/verify-adjust.mjs status
```

期望看到：

- 总数 22
- 待回炉：fresh 模式为 0，demo 模式为 2
- 计划版本 v1

## 四、录视频的标准流程

1. 停止上一轮留下的页面操作，执行 `reset-demo demo`。
2. 刷新浏览器（Ctrl+F5 强制刷新）。
3. 开始录屏。
4. 讲完主线后，执行 `reset-demo demo` 恢复状态，再重录。
5. 录完最终版后执行一次 `reset-demo demo`，保证交付时的演示数据是主线状态。

整个重置过程约 5 到 10 秒（包含一次规划师调用）。

## 五、不想用脚本时的最快操作

如果脚本临时不可用，可以按下面步骤手工走：

1. 删除 `data/learning-planner.db`、`data/learning-planner.db-shm`、`data/learning-planner.db-wal` 三个文件。
2. 重启服务（`Ctrl+C` 后重新 `npm run dev`）。
3. 打开知识库页，确认 22 个知识点已自动载入。
4. 打开学习计划页，输入"我想在三周内学懂大学计算机基础，为期末考试做准备"，点"按默认直接生成"。
5. 打开今日学习页，对第一个知识点提交一个含糊回答，让它变成"待回炉"；再对第二个知识点重复一次。
6. 打开进度页，确认待回炉为 2，即可开始演示调整链路。

全程约 1 分钟。

## 六、常见问题

| 现象 | 原因 | 怎么办 |
|------|------|--------|
| 提示"调用规划师失败" | 模型配置缺失或网络异常 | 检查 `.env`，确认服务已启动 |
| 重置后页面还是旧数据 | 浏览器缓存 | Ctrl+F5 强制刷新 |
| 提示数据库被占用 | 服务正在写入 | 等两秒再执行；仍失败则重启服务 |
| 重置后知识点不是 22 个 | 讲义文件被改动 | 检查 `docs/大学计算机基础_课堂讲义.md` 是否存在 |
