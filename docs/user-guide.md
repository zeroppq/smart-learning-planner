# 使用说明

## 一、这是什么

智学规划是一个给大学生用的网页学习系统。你说清楚想学什么，它帮你排出学习路线和每天的任务；每天先抽查旧知识，再带你学新知识，并用"讲清楚 → 做对题 → 做出来"三层判断你是不是真的学会了。

不需要注册登录，数据保存在本机。

## 二、第一次使用要准备什么

1. 电脑上安装 Node.js（版本 22 或更高）。
2. 在项目根目录准备一个 `.env` 文件，填入模型服务配置：

```
MODEL_API_BASE_URL=模型服务地址
MODEL_API_KEY=你的密钥
MODEL_NAME_PLANNER=deepseek-v4.1-flash-1017
MODEL_NAME_COACH=deepseek-v4.1-flash-1017
```

`.env` 只放在本机，不要发给别人，也不要提交到代码仓库。

## 三、启动系统

在项目根目录打开命令行，依次输入：

```
npm install
npm run dev
```

看到 `Ready` 后，浏览器打开 http://localhost:3000 。

## 四、四个页面怎么用

### 1. 知识库（/knowledge）

- 第一次打开会自动载入《大学计算机基础》讲义，共 22 个知识点。
- 想用自己的资料：点"选择文件"，支持 TXT / MD / PDF，单个不超过 10MB。
- 传完点资料名，下面会列出切出来的知识点；点某个知识点，底部显示"原文出处"（文档名 + 第几段）。

### 2. 学习计划（/plan）

1. 在输入框写一句目标，例如"我想在三周内学懂大学计算机基础，为期末考试做准备"。
2. 每天可用时长默认 40 分钟，可以改。
3. 点"开始规划"，规划师可能问 1-3 个问题，可以回答，也可以点"按默认直接生成"。
4. 生成后左边是路线图（含前置依赖），右边是每日任务。

### 3. 今日学习（/）

1. 进入页面后督学会自动先抽查，或者显示开场提示。
2. 点某个任务的"开始学习"，督学会先讲知识点，并把三层判定标准完整列出来。
3. 第一层"讲清楚"：用自己的话复述，督学会追问。
4. 第二层"做对题"：督学出题，你独立作答；答错可以换一道变式题。
5. 第三层"做出来"：督学给一个应用型小任务，你提交文字方案，督学按标准评阅。
6. 判定不过时，可以申请重判一次，需要写补充说明。
7. 页面底部可以随时提问，回答会标注来源文档与段落。

### 4. 进度（/progress）

- 四个数字：已通过 / 总数、待回炉、连续学习天数、到期复习。
- 路线图用四种颜色区分状态：未学、学习中、已通过、待回炉。
- 点"让规划师看看要不要调整"，会出现调整方案：写清原因、调整前后对比，你点"确认调整"才会生效，计划版本号会加一。

## 五、数据存在哪

所有数据保存在项目目录的 `data/learning-planner.db` 文件里。备份这个文件就等于备份全部学习记录。

## 六、常见问题

| 现象 | 原因 | 怎么办 |
|------|------|--------|
| 页面提示"模型服务尚未配置" | `.env` 没填或没填全 | 按第二节填好三项，重启服务 |
| 上传 PDF 提示解析失败 | 扫描件或文件损坏 | 改用 MD / TXT |
| 生成计划提示"原计划保持不变" | 模型返回异常 | 再点一次生成；原计划不会丢 |
| 页面打不开 | 服务没启动 | 重新执行 `npm run dev` |
| 想从头再来 | 演示数据乱了 | 看《演示重置说明》，一条命令恢复 |
