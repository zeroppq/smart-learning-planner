# 规划师接口说明

## 一句话职责

规划师负责"学什么、按什么顺序学、每天学多少"，不负责判定学生是否学会。

## 系统提示词放在哪

`src/lib/agents/planner/system-prompt.ts`。提示词独立于业务代码，后续打磨措辞只改这一个文件，不需要动接口和页面。

## 接口一：创建目标并获取澄清问题

`POST /api/goals`

| 项目 | 说明 |
|------|------|
| 输入 | `goalText`：一句话学习目标，2-200 字；`dailyMinutes`：每天可用时长，10-240 分钟 |
| 成功返回 | `{ ok: true, goal: {...}, questions: ["问题1", "问题2"] }` |
| 问题数量 | 最多 3 个；如果目标已经足够清楚，返回空数组 |
| 失败返回 | 400 + 中文原因，例如"请用一句话说明你想学什么" |

说明：生成澄清问题失败时不影响主流程，返回空数组，用户可直接生成计划。

## 接口二：生成学习计划

`POST /api/plans`

| 项目 | 说明 |
|------|------|
| 输入 | `goalId`：目标编号；`answers`：可选，澄清问题的回答，最多 3 条 |
| 处理过程 | 读取知识库里真实存在的知识点 → 交给规划师排顺序与前置依赖 → 校验结果 → 写入计划与每日任务 |
| 成功返回 | `{ ok: true, plan: {...} }`，含 `route`（路线图）与 `daily_tasks`（每日任务） |
| 知识库为空 | 400，"知识库里还没有可用知识点，请先上传并把资料解析成功" |
| 模型输出不可解析 | 502，"计划生成结果不可用…原计划保持不变，请重试" |
| 模型未配置 | 503，中文说明缺少哪些环境变量 |
| 模型调用失败 | 502，中文说明，原计划保持不变 |
| 保存失败 | 500，原计划保持不变 |

关键约束：

1. 路线图只允许使用知识库里已有的知识点。规划师编造不存在的知识点时，本次生成直接作废。
2. 前置依赖不能指向自己，也不能形成环。
3. 每日任务每天最多 3 项，全部落在 14 天周期内。
4. 生成或保存任何一步失败，都不会修改已有计划。

## 接口三：读取当前计划

`GET /api/plans/current`

返回当前进行中的目标、路线图、每日任务与今天的任务。没有计划时返回 `{ ok: true, plan: null }`。

## 数据落在哪里

| 内容 | 表 | 关键字段 |
|------|----|----------|
| 学习目标 | `learning_goal` | `learning_goal_id`、`goal_text`、`daily_minutes`、`goal_status` |
| 计划版本 | `plan` | `plan_id`、`plan_version`、`route_json` |
| 前置依赖 | `knowledge_point` | `prerequisite_point_id` |
| 每日任务 | `daily_task` | `task_date`、`estimated_minutes`、`task_status` |

## 换模型怎么改

只需要改环境变量，不改代码：

- 规划师：`MODEL_NAME_PLANNER`（缺省回落到 `MODEL_NAME`）
- 督学：`MODEL_NAME_COACH`（缺省回落到 `MODEL_NAME`）
- 接口地址：`MODEL_API_BASE_URL`
- 密钥：`MODEL_API_KEY`（只写在本地 `.env`，不提交）
