## 框架能力（供后续组复用）

| 能力 | 说明 |
|------|------|
| `open(path)` | 打开本地页面并等待渲染 |
| `clickByText(selector, text)` | 按文字找按钮并点击 |
| `fill(selector, value)` | 向输入框/文本域填内容（兼容 React 受控组件） |
| `waitForText(needle, timeout)` | 轮询等待页面出现指定文字（默认 30 秒） |
| 路径注册表 | `paths` 数组逐条执行，失败时打印该路径的手工清单；环境级失败统一 `ENV_FAIL` 前缀，便于区分"环境问题"与"断言失败" |
