# 比赛材料与开发痕迹目录

本目录用于沉淀华为云比赛"码道使用深度"与"材料规范"两项需要的证据。所有内容随代码一起提交（`.gitignore` 不忽略本目录）。

## 目录用途

| 目录 | 放什么 | 提交方式 |
|------|--------|----------|
| `prompts/` | 规划师、督学两个智能体的提示词版本与修改记录，文件名建议 `planner-v1.md`、`coach-v1.md` | 直接提交文本 |
| `screenshots/` | 关键页面截图：知识库、计划、今日学习、进度、模型调用成功、测试通过 | 提交压缩后的图片，单张建议小于 500KB |
| `recordings/` | 开发过程录屏与演示视频的清单（文件名、时长、存放位置、录制日期） | 只提交清单 `recording-list.md`，大体积视频存网盘 |
| `git-log/` | 按任务组导出的提交记录，用于展示开发节奏，文件名建议 `group-1.txt` | 直接提交文本 |

## 约定

1. 截图命名：`<日期>-<页面或动作>.png`，例如 `2026-11-15-knowledge-upload.png`。
2. 录屏清单必须写明网盘位置，避免只留文件名找不到文件。
3. 不放入任何密钥、账号、内网地址或个人隐私信息。
4. 比赛提交前检查：四个目录都至少有一份内容，不能是空目录。
